# Протокол CTP/1.0 (Chess Threat Protocol)

Транспорт — TCP, порт по умолчанию **5025**. Текстовый построчный протокол:
каждая команда и каждый ответ — одна строка UTF-8, оканчивающаяся `\n`
(`\r\n` тоже допускается). На одно соединение — сколько угодно запросов.

| Запрос | Ответ |
|---|---|
| `CHECK <король> <ладья> <слон>` | `OK <NONE\|ROOK\|BISHOP\|BOTH> <текст>` |
| `PING` | `PONG` |
| `STATS` | `OK requests=<n> clients=<n> errors=<n>` |
| `VERSION` | `OK chess-threat-server CTP/1.0 lib <версия>` |
| `HELP` | `OK команды: ...` |
| `QUIT` | `BYE`, сервер закрывает соединение |

Ошибки: `ERR <код> <описание>`

| Код | Причина |
|---|---|
| 400 | неизвестная команда, неверное число аргументов, пустой запрос |
| 413 | строка длиннее 4096 байт (соединение закрывается) |
| 422 | клетка вне доски или фигуры на одной клетке |

Пример сеанса (`nc 127.0.0.1 5025`):

```
CHECK e1 e8 h4
OK BOTH Королю угрожают ладья с e8 и слон с h4 (двойной шах).
CHECK e1 e8 e4
OK NONE Угрозы королю нет.
QUIT
BYE
```
